# Release checklist

- [ ] No failing tests
- [ ] No known critical/high security finding
- [ ] No exposed secret
- [ ] Fresh install and production build succeed
- [ ] Migration and rollback rehearsed
- [ ] Backup restored and verified
- [ ] Workspace isolation and authorization pass
- [ ] Browser/accessibility smoke pass
- [ ] Load targets pass
- [ ] Container health and image scan pass
- [ ] SBOM, checksums, provenance, immutable version produced
- [ ] Staging deployment and post-deploy verification pass
- [ ] Known limitations and residual risks approved

A box may be checked only with retained evidence.
