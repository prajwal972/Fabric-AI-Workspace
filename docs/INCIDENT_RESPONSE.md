# Incident response

1. Declare severity and incident commander; preserve request IDs, audit events, metrics, and immutable logs.
2. Contain: revoke sessions/tokens, disable affected connectors/providers, block egress, quarantine uploads, or drain the deployment.
3. Eradicate the cause and rotate exposed keys using a documented key-version plan.
4. Recover from a verified backup or clean immutable release; validate tenant isolation and integrity.
5. Notify affected parties under the applicable policy and law.
6. Publish a blameless review with timeline, scope, evidence, corrective actions, owners, and deadlines.

Do not paste secrets or private user content into tickets or chat channels.
