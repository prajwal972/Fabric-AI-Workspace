# Data and privacy policy template

Document the controller/operator, purposes, data categories, subprocessors and regions, retention, legal basis, user rights, security controls, breach contact, and deletion/export SLA. State which model, speech, OAuth, storage, monitoring, and backup providers receive data. Fabric does not intentionally persist raw voice audio by default; optional Azure processing sends audio to the configured Azure region. Replace this template with reviewed organization-specific terms before launch.
